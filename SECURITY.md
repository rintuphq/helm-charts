# Security policy

## Reporting a vulnerability

Please report security problems privately by e-mail to **security@rintup.com**. Do not open a public
GitHub issue for them.

Include what you found, how to reproduce it, the chart version and your Kubernetes version.
We confirm receipt and keep you updated while we work on a fix.

## Supported versions

Fixes are released as a new chart version. Upgrade to the latest version of
`oci://ghcr.io/rintuphq/charts/rintup-agent` to receive them.

## Verifying releases

Chart releases are signed with cosign (keyless). See "Verifying signatures" in the [README](README.md).
